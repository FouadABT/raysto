## Historical records

Documents including `backend-setup.md`, `firebase-integration.md`, `backend-implementation.md`, `product-direction.md` and `web-phase-1.md` record successive stages. Dated descriptions are not a cumulative claim that every proposed feature is live. **Project status** above is the current reviewer entry point.

Private provider responses, account screenshots, local logs and one-off host provisioning scripts stay outside public source. Historical mentions of `docs/qa/`, `docs/runtime/`, `dist/`, `.tooling/`, `deploy/ec2/` and `web/artifacts/` refer to local work products. They are not required runtime dependencies or public downloads.
